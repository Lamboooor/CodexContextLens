# Security

This extension processes potentially sensitive local session text. It must not read authentication files, transmit session content, modify Codex logs or execute commands from log content.

Only the latest preview receives fixes; no long-term support schedule is promised.

## Reporting

If GitHub shows **Security → Report a vulnerability**, use that private channel. If it is unavailable, open an issue containing only a request for a private contact method; do not include exploit details, credentials or private logs. The maintainer will arrange a channel before asking for details. Ordinary display or parsing bugs belong in the standard bug template.

No response-time guarantee or bug bounty is offered. Thank you for helping keep private session data private.

安全问题优先通过仓库的私密漏洞报告入口提交。如入口不可用，请只公开询问私密联系方式，不要发布漏洞细节或敏感日志。
