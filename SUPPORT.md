# Support / 支持

Use [GitHub Issues](https://github.com/Lamboooor/CodexContextLens/issues/new/choose) for bugs and feature requests. Search existing issues first. This is a community project with no guaranteed response time.

## A useful bug report

- Extension, VS Code, OS and Codex versions.
- Local, WSL, SSH or container environment.
- Reproduction steps, expected result and actual result.
- Whether the issue affects the hover, sidebar or full dashboard.
- A redacted screenshot, if helpful. Remove titles, usernames, paths and session IDs.

**Never post auth.json, access tokens, cookies, API keys or complete session logs.** Use synthetic examples. See [troubleshooting](TROUBLESHOOTING.md) before filing.

## Scope

The extension reads local snapshots; it cannot change subscription limits, see the server's live context, or recover missing log fields. Native hover redraw, approximate source attribution and remote-host limitations are documented in the README.

问题反馈请使用上方 GitHub Issues。请附版本、运行环境、复现步骤和脱敏截图，不要提交完整日志或认证资料。安全问题请遵循 [SECURITY.md](SECURITY.md)。
